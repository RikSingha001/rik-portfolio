About Me

My journey in software development

I'm Rik Singha, a self-taught Full Stack Developer with strong expertise in Python Django, JavaScript, and PHP, driven by a deep curiosity about how software works. My journey in tech began with self-learning and hands-on experimentation, leading to several real-world projects that strengthened my skills and passion for development.


One of my earliest milestones was creating a user authentication system entirely in PHP, which became the foundation for more complex work. Later, I developed a Cab Booking System using Next.js, where I built a vendor dashboard with role-based access for users, drivers, and vendors – a project that sharpened my problem-solving and full-stack capabilities.


I specialize in Python Django development, creating robust web applications with clean architecture and efficient database design. My experience extends to data analysis with NumPy, Pandas, and Matplotlib. I focus on building data-driven applications that combine powerful backend systems with intuitive user interfaces.


Outside of work, I enjoy exploring emerging technologies, experimenting with coding concepts, and reading books that broaden both my technical and creative thinking. I'm always eager to collaborate on Django projects and web development initiatives, contributing to building innovative, impactful software solutions.
