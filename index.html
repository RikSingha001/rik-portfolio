About Me

My journey in software development

I'm Rik Singha, a self-taught Python Developer specializing in the Django framework. Driven by a deep curiosity about back-end architecture and scalable systems, I focus on building robust, secure, and data-driven web applications.


My journey into software development began with a fascination for automation and logic, which led me to master Python. One of my key development milestones includes building a comprehensive Cab Booking System. This project featured a complex vendor dashboard and sophisticated role-based access control, allowing me to solve real-world problems through clean code and efficient logic.


I specialize in Python Django development, where I prioritize clean architecture and optimized MySQL database design. I have a strong command over relational data modeling, ensuring that applications are not only fast but also highly scalable and secure at the data layer.


Currently pursuing my BCA at Uttaranchal University, I am dedicated to continuous learning and staying at the forefront of the Python community. I am always eager to collaborate on Django-based projects and contribute to building innovative, high-impact software solutions that scale.
